# 🚀 My Personal Portfolio Website
  
## 🌐 Live Portfolio  
🔗 [Visit My Portfolio](https://lxance-hacker.github.io/Portfolio/)

## 📌 About  
This is my personal portfolio website, designed with a **hacker-themed** aesthetic and a **blur effect** on the background image as the user scrolls. The website is fully **responsive** and professionally designed.  

## 🎨 Features  
- 🔥 **Hacker-Themed UI**  
- 🎭 **Dynamic Blur Effect on Scroll**  
- 📱 **Fully Responsive & Mobile-Friendly**  
- 🚀 **Smooth Animations with Framer Motion**  
- 🎨 **Tailwind CSS for Clean Styling**  

## 🚀 Installation & Setup  
1. Clone the repository:  
   ```sh  
   git clone https://github.com/LxaNce-Hacker/Portfolio
   ```  
2. Navigate to the project directory:  
   ```sh  
   cd Portfolio  
   ```  
3. Open `index.html` in your browser to view the portfolio.
